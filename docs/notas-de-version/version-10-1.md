# Versión 10.1

Sebastian HR 10.1 amplía lo que puedes consultar y detectar con asistentes de IA. También actualiza la documentación de la Web API y corrige el envío de horas extra validadas a la bolsa.

## Otras novedades

### Ausencias y vacaciones

- **Consultas con el asistente:** consulta las vacaciones y los permisos de tu equipo y de las personas a tu cargo.

### Asistentes de IA y Web API

- **Fichajes pendientes:** los asistentes de IA pueden detectar quién tenía que fichar y no lo hizo. [Más información](../integraciones/web-api.es.md)
- **Documentación:** la Web API incluye información sobre ausencias no planificadas y parámetros de MCP. [Más información](../integraciones/web-api.es.md)

## Correcciones

??? note "Ver las correcciones de esta versión"

    - **Bolsa de horas:** vuelve a ser posible enviar a la bolsa las horas extra validadas aunque el convenio no las calcule. [Más información](../horas/bolsa-de-horas.es.md)
