# Guía de Usuario: Nuevo Sistema de Jornadas

## Guía de Usuario – Nuevo Sistema de Jornadas

### ¿Qué ha cambiado?

Hemos mejorado cómo el sistema gestiona las jornadas laborales. Ahora se registra todos los días , no solo los que tienen fichajes.



### Beneficios para los usuarios

### Visibilidad completa del calendario laboral

Antes: Solo se mostraban días con fichajes.  
Ahora: Se muestran todos los días activos:

  * Días trabajados (con fichajes)
  * Vacaciones
  * Bajas médicas
  * Festivos
  * Días libres según turno

### Mejor auditoría

Se registra quién reabrió una jornada y el motivo.

 

### ¿Cómo funciona ahora?

### Flujo normal de una jornada
    
    
    1. GENERADA → 2. VALIDADA → 3. CONSOLIDADA
    (abierta)        (revisada)        (cerrada)

### ¿Cuándo se genera una jornada?

  1. Al fichar
  2. Al cerrar periodo (vacaciones, bajas...)
  3. En proceso nocturno (opcional)

 

### Preguntas frecuentes

### ¿Veré más registros en la lista de jornadas?

```
Sí. Ahora aparecen todos los días activos, incluso sin fichajes.
```
### ¿Qué pasa si añado un fichaje a un día validado?

  * El fichaje se registra normalmente
  * La jornada se marca como “pendiente de revisión”
  * El gestor debe revisarla y revalidar

### ¿Puedo modificar una jornada consolidada?

Un gestor autorizado debe:

  1. Abrir la jornada consolidada
  2. Seleccionar “Deshacer consolidación”
  3. Indicar motivo
  4. Modificar lo necesario
  5. Volver a validar y consolidar

### ¿Qué información contiene cada jornada?

  * Minutos trabajados
  * Minutos planificados
  * Minutos teóricos
  * Minutos de ausencia
  * Turno
  * Oficina y empresa
  * Festivo
  * Vacaciones o bajas

### ¿Afecta esto a los informes?

No, pero ahora tienen información más completa.
